# Windows-ad-homelab-
A self hosted home lab simulating IT infrastrucutre  like windows server active directory deployed on virtualbox, covering domain services, user/group managment and GPO's
## 🎯 Goals
- 🏗️ Set up and configure Active Directory Domain Services
- 👥 Practice user, group, and OU management
- 📋 Configure Group Policy Objects (GPOs)
- 🌐 Configure DNS and DHCP
- 📝 Document the build process step by step

## 🛠️ Tools
- 📦 VMware Workstation
- 🪟 Windows Server (evaluation edition)
- 💻 Windows 10/11 client VM
